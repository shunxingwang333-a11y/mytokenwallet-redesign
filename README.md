# MyTokenWallet Next

An alternative, independent MyTokenWallet website concept built with React, Vite, Tailwind CSS, and Supabase. This project lives in a separate repository and Vercel project from the original site.

## Features

- Reimagined responsive marketing pages with a new visual system and app dashboard artwork
- Wallet download, security, asset operations, discovery, and journal sections
- Supabase-backed article listing, article details, and administration
- Article-level page titles, descriptions, keywords, and structured data
- SEO discovery endpoints and live XML / text sitemaps

## Development

```sh
pnpm install
pnpm dev
```

Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in the Vercel project to enable the existing editorial backend.
